# CarBug

مرجع فارسی تشخیص ایراد خودرو از روی صدا، بو و دود؛ سایت ایستا برای GitHub Pages.

## امکانات
جستجوی فارسی، فیلتر دسته/نوع صدا/شدت/خودرو، نقشه‌ی محل صدا، عیب‌یاب مرحله‌ای، مقایسه‌ی ۳ مورد، چراغ‌های داشبورد، هزینه‌ی نسبی، ذخیره‌ی موارد، لینک مستقیم، لینک نمونه‌صدا (یوتیوب، اسپاتیفای، آپارات)، پرینت، تم روشن/تاریک، PWA آفلاین و قابل نصب، فونت وزیرمتن.

## انتشار
فایل‌ها را در یک مخزن بگذارید. در Settings ← Pages منبع را روی «GitHub Actions» بگذارید؛ workflow انتشار خودکار است.

## افزودن ایراد
```js
{cat:"موتور",t:"تق‌تق",sev:2,cost:1,title:"...",sound:"...",when:"...",causes:["..."],act:"...",
 q:"engine knocking sound", m:["پراید"], audio:"sounds/x.mp3"}
```
`sev` شدت (1 تا 3)، `cost` هزینه‌ی نسبی (1 تا 3)؛ `q`، `m` (خودروی خاص)، `link` (لینک مستقیم یک نمونه‌صدا در یوتیوب، اسپاتیفای و…) و `audio` (فایل داخل پوشه‌ی `sounds/`) اختیاری‌اند. قبل از PR: `node scripts/validate.js`.

## نکته
داده‌ها راهنما هستند و باید با مکانیک تأیید شوند. هزینه‌ها عمداً نسبی‌اند چون قیمت مطلق سریع تغییر می‌کند.

## مسیر صداها
۱. اول `link` را برای هر مورد بگذارید (ارجاع به منبع بیرونی).
۲. بعداً فایل‌های صوتی دارای مجوز را در `sounds/` بگذارید و `audio:"sounds/نام.mp3"` را اضافه کنید؛ بعد از اولین پخش، سایت آن را برای استفاده‌ی آفلاین ذخیره می‌کند.
